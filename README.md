## 关于我

> 当初选 Python 纯粹是因为听说它入门简单 😂  
> 结果一入坑发现要学的东西还挺多。

目前的学习方式比较原始——**边做边学**，每学一个知识点就写一个能跑的小玩意把它巩固住。代码写得糙，但能跑就是胜利 ✌️

最近在啃 **面向对象**，然后打算往 **数据分析** 方向走一走，看看 pandas 和 matplotlib 能做点什么。
